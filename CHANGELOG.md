# Changelog

## [0.3.0](https://github.com/ainsel-project/ainsel/compare/v0.2.0...v0.3.0) (2026-11-14)


### ⚠ BREAKING CHANGES

* **hub:** GET /api/internal/agents/{name}/next-task returns 404 and TASK_CLAIM_TIMEOUT_SECONDS is ignored.
* **frontend:** edit tools and skills on the agent, not the image
* **pi:** enforce the agent's tool selection with ainsel-tools
* **api:** scope tool and skill selection to the Agent
* **operators:** a plain-HTTP registry that is not listed in --insecure-registries no longer resolves image digests, so agents on it lose restart-on-rebuild until the host is added to the list.
