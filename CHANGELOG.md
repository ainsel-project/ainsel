# Changelog

## [0.3.0](https://github.com/ainsel-project/ainsel/compare/v0.2.0...v0.3.0) (2026-11-17)


### ⚠ BREAKING CHANGES

* **chart:** align component names across code, templates and values
* document the pause removal and point at replicas: 0
* **frontend:** remove the pause control from the console
* **hub:** remove the agent pause API
* **operator:** stop mirroring pause state in the agent controller
* **api:** drop spec.pause and status.paused from the Agent CRD
* **chart:** compose project images from global.imageRegistry
* **hub:** GET /api/internal/agents/{name}/next-task returns 404 and TASK_CLAIM_TIMEOUT_SECONDS is ignored.
* **frontend:** edit tools and skills on the agent, not the image
* **pi:** enforce the agent's tool selection with ainsel-tools
* **api:** scope tool and skill selection to the Agent
* **operators:** a plain-HTTP registry that is not listed in --insecure-registries no longer resolves image digests, so agents on it lose restart-on-rebuild until the host is added to the list.
